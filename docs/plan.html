StoreOps

Convenience Store Order Management System

Hệ thống quản lý sản phẩm & đơn hàng nội bộ
dành cho chuỗi cửa hàng tiện lợi

Spring Boot 4.x
Next.js 14
PostgreSQL
Supabase
JWT Auth
Docker
Vercel
01 — Scenario
Nhân viên cửa hàng (Staff) duyệt danh sách sản phẩm trong kho và tạo đơn nhập hàng gửi lên quản lý. Admin (Store Manager) quản lý danh mục hàng hóa và duyệt / theo dõi các đơn nhập hàng. Hệ thống phân quyền rõ ràng — mỗi role chỉ thấy và thực hiện được chức năng của mình.
🛡️

Admin — Store Manager

  • Quản lý sản phẩm: thêm, sửa, xóa
  • Xem danh sách & chi tiết sản phẩm
  • Xem toàn bộ đơn hàng
  • Cập nhật trạng thái đơn hàng
  • Dashboard thống kê tổng quan
👤

Staff — Store Employee

  • Xem danh sách sản phẩm
  • Tìm kiếm & lọc theo category
  • Thêm sản phẩm vào giỏ hàng
  • Tạo & gửi đơn nhập hàng
  • Xem lịch sử đơn của mình
02 — Milestones
M1
Foundation & Auth Tuần 1
BESetup Spring Boot, cấu hình Security + JWT
DBTạo schema storeops trên Supabase, Flyway migrations
BEAuthController: login, refresh token, logout
FESetup Next.js 14, Tailwind, shadcn/ui, TanStack Query
FETrang login + Zustand auth store + route guard
OPSDocker Compose (BE + PostgreSQL local), GitHub repo
M2
Product Module Tuần 2
DBMigration: bảng products, categories
BEProductController: CRUD + phân quyền theo role
BEValidation, GlobalExceptionHandler, ApiResponse wrapper
FEAdmin: product table, modal thêm/sửa, confirm xóa
FEStaff: product grid, search, filter theo category
BESwagger UI + Springdoc OpenAPI config
M3
Order Module Tuần 3
DBMigration: bảng orders, order_items
FEStaff: Cart drawer, chọn sản phẩm, submit order
BEOrderController: tạo đơn, validate stock, tính total
BEOrder status flow: PENDING → APPROVED → DELIVERED
FEAdmin: order list, filter theo status, xem chi tiết
FEOrderStatusBadge + update status action
M4
Polish & Deploy Tuần 4
FEPagination, search, sort cho product & order list
FEAdmin dashboard: cards thống kê, low stock warning
FELoading state, empty state, error handling toàn bộ FE
OPSDeploy BE lên Railway/Render, FE lên Vercel
OPSGitHub Actions CI: build + test khi push/PR
OPSREADME: setup guide, screenshots, Postman collection

05 — GitHub Strategy
📁 StoreOps/ ← monorepo
├── backend/    ├── frontend/    ├── docker-compose.yml    └── README.md
main Production-ready, protected — chỉ merge qua PR đã review
develop Integration branch — merge tất cả feature vào đây trước khi lên main
feature/auth-jwt Mỗi tính năng 1 nhánh, ví dụ: feature/product-crud, feature/order-create
fix/order-status Hotfix branches, merge thẳng vào develop sau khi fix
